# 人设（ai-persona）

AI 聊天的**系统提示词唯一来源**：说谁（人设表）、怎么说话（说话风格）、群聊/私聊各用哪套。

1.1.0 起融合了 QQ Agent 技能 **tieba-mouth 1.1.0（贴吧鱼模式）**：被 @ 说一句「切换贴吧鱼模式」，
这个群就改用贴吧吧友的口吻；说「关闭贴吧模式」切回来。语料库按贴吧出处（吧名/句式/梗）整理，
开着模式时每轮抽几条塞进提示词——不额外花 token，也不用模型自己"想起"自己在贴吧模式。

---

## 两条命令

| 场景 | 说法 |
|---|---|
| 开启 | `@机器人 切换贴吧鱼模式`（也认：开启/打开/切到贴吧鱼模式、贴吧鱼模式；前面可加 帮我/请/麻烦/给我/现在/立刻/赶紧/快点） |
| 关闭 | `@机器人 关闭贴吧模式`（也认：关闭贴吧鱼模式、退出贴吧鱼模式、退出贴吧模式、关掉贴吧模式、贴吧模式关闭） |
| 查状态 | `@机器人 贴吧`，或 `/贴吧`、`/贴吧 状态` |
| 显式开关 | `/贴吧 开`、`/贴吧 关`（私聊也能用） |

- 按会话（群号）独立生效，A 群开了不影响 B 群；状态落盘 `tieba-modes.json`，重启不丢。
- 群里默认必须 @ 才认自然语言切换；`/贴吧 开` 这种显式命令不用 @。
- 命中切换指令会立刻回一句（回复里固定带「进入贴吧模式」/「退出贴吧模式」），并且**不再交给 AI 回**，避免模型再补一句"好的我切换了"。

## 开启后注入什么

`persona.render` 给 ai-chat 的系统提示词里会多两段（只有开着模式的会话才加）：

1. **静态口吻**：孙吧对线风格 + （默认）《身份定位》见人就骂的人格底色 + 无解死锁话术 + 分条打字铁律 + AI 味黑名单 + 现实底线（不开盒/不线下/不涉未成年/不冒充管理员）。
2. **本轮语料**：`【贴吧语料·本轮】` + 6 条（默认）`词：含义（吧名）`，按 `口癖:句式:接话:梗 ≈ 3:1:1:1` 抽；同一轮/同一时间窗内稳定，每 `rotateMinutes` 分钟换一批。

设置项 `tieba_identity` 关掉就只保留原来的嘴臭腔调，不注入身份定位/对线技能。

**战斗模式（2026-10-26 起）**：

- 群里**不用 @ 也会接话**：开着贴吧模式的会话，每条消息 **80%** 概率回复，不受 @设置/冷却限制
- **每轮至少 30 字**：不管分几条发，总字数要够 30（ai-chat 会检查，不够就补说一轮）
- 主动开战：不用等人骂，看到有人说话就挑刺开团，连发 2~3 条

## 语料库

- 种子 112 条（孙笑川吧 / 李毅吧 / 帝吧 / 抗压背锅吧 / 戒赌吧等），随插件打包：`app/tieba_corpus.js`
- 运行时副本：`<插件 data 目录>/tieba-corpus.json`（Windows 下一般是
  `C:\qqbot\data\plugins\ai-persona\data\tieba-corpus.json`）
- 每条：`{ kind, phrase, meaning, bar, example }`，`kind ∈ slang | pattern | reply | meme`
- 两种扩法：
  1. 模型调用工具 `tieba_add`（`phrase` 必填，`kind/meaning/bar/example` 可选），重复 phrase 只更新解释
  2. 直接改 `tieba-corpus.json` 的 `items` 数组
- 看统计：工具 `tieba_stats`（按 kind 计数 + 出处 Top6 + 抽样）
- 恢复出厂：删掉 `tieba-corpus.json`，重启后按种子重建
- 插件更新带来的新种子会自动并入，不覆盖用户自己加的；上限 800 条

## 设置（9 项）

| key | 默认 | 说明 |
|---|---|---|
| `system_prompt` | 一段基础提示词 | 所有人设共用 |
| `bot_name` | 空 | 机器人自称 |
| `speaking_style` | 空 | 说话风格补充 |
| `tieba_enabled` | 开 | 总开关；关掉后不认指令、已开着的会话也立刻恢复 |
| `tieba_identity` | 开 | 是否注入《身份定位》/对线技能 |
| `tieba_require_mention` | 开 | 群里自然语言切换是否必须 @ |
| `tieba_sample_count` | 6 | 每轮抽几条语料（2–20） |
| `tieba_rotate_minutes` | 3 | 换批间隔分钟（1–60） |
| `tieba_blocked_words` | 空 | 逗号/空格分隔，命中的语料不注入 |

## 为什么融合进人设插件

贴吧模式的本质是"换一套系统提示词 + 按群开关"。QixinBot 里系统提示词只有一个出口
（本插件的 `persona.render`），拆成两个插件的话 ai-chat 要同时问两家、还得保证注入顺序，
状态与开关也会散在两处。所以这里把它做成 `app/tieba.js` 的一个能力模块：

- `tieba.js`：指令识别、模式状态、语料库、抽词、提示词片段（不依赖 host，方便单测）
- `tieba_rules.js`：从原插件原样移植的提示词常量与切换文案
- `tieba_corpus.js`：112 条种子语料
- `index.js`：接 `handle_message`（先问 tieba，再走 `/人设`）、`render()` 追加、`call_tool` 暴露工具

## 与 ai-chat 的记忆隔离

贴吧鱼模式有**自己的一套记忆**，和正常聊天完全隔离：

- 开模式时：用户消息和机器人回复都写进 `ai_tieba_message`，**不写** `ai_message`
- 开模式时：上下文只从这个会话的 `ai_tieba_message` 里取，**不读**原记忆
  （跨会话个人记忆 `ai_message`、群的语气/黑话统计都不读）
- 关模式后：读写立刻回到 `ai_message`，贴吧那段历史不会串进来
- ai-persona 提供能力 `persona.mode`（`{ tieba: true/false }`），ai-chat 靠它决定走哪套

原因：那种嘴臭台词一旦混进正常历史，切回正常人设后模型会照着上一轮语气接，容易出事；
反过来贴吧模式里读到以前的软话，也会把腔调拉回去。

## 边界

- 语料是风格参考，不是台词：注入的是"词：含义（吧名）"，模型自己组织句子。
- 嘴臭是对线模式的一部分，但现实边界不变：不开盒、不约线下、不涉未成年、不写性暴力细节、不冒充管理员。
- 指令识别只做字符串匹配，`require_prefix = false` 下每条消息都会经过，但不做 IO，不拖慢分发。
- 状态和语料只写插件 data 目录，不写 plugins 目录（避免触发全量重扫）。
