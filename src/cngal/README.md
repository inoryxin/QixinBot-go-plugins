# 国 G 周报（cngal）

每周把 CnGal 的国 G 动态、即将发售、折扣画成一张长图发到群里

## 基本信息

| 项 | 值 |
|---|---|
| 版本 | v1.1.1 |
| 语言 | Node.js |
| 权限 | onebot.write |
| 观察全量消息 | 否 |
| 提供能力 | cngal.preview@1 |

## 安装

把 `packages/cngal.anzu` 丢进框架的 `plugins/` 目录（或从[插件商店](https://github.com/inoryxin/QixinBot-go-plugins#插件商店)下载），
去控制台「插件」页启用。依赖说明见仓库 README。

## 开发调试

在本目录改代码后，用 `qixinpack dev`（假协议端 + 热重载）验证；详见仓库 README「创建一个插件」。
