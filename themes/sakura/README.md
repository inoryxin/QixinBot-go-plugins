# 🌸 樱花庭园（sakura）

樱花玻璃拟态：毛玻璃卡片、花瓣飘落、粉彩配色（浅色=昼樱，深色=夜樱）

## 基本信息

| 项 | 值 |
|---|---|
| 版本 | v1.0.0 |
| 语言 | Node.js |
| 权限 | 无 |
| 观察全量消息 | 否 |
| 提供能力 | 无 |

## 安装

这是控制台**主题**：把 `packages/sakura.anzu` 在控制台「主题」处导入（或按 WebUI 的主题安装入口），即可切换外观。

## 开发调试

在本目录改代码后，用 `qixinpack dev`（假协议端 + 热重载）验证；详见仓库 README「创建一个插件」。
