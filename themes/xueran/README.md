# 🐱 许雪然（xueran）

许雪然导航页同款：粉彩玻璃卡片、左下雪然立绘、右下看板娘、logo 替换（素材来自 home.inory.xin）

## 基本信息

| 项 | 值 |
|---|---|
| 版本 | v1.0.0 |
| 语言 | Node.js |
| 权限 | 无 |
| 观察全量消息 | 否 |
| 提供能力 | 无 |

## 安装

这是控制台**主题**：把 `packages/xueran.anzu` 在控制台「主题」处导入（或按 WebUI 的主题安装入口），即可切换外观。

## 开发调试

在本目录改代码后，用 `qixinpack dev`（假协议端 + 热重载）验证；详见仓库 README「创建一个插件」。
